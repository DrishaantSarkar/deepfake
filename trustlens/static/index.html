What happens to this file?

The original is staged temporarily for analysis and deleted when processing returns. This app saves the report and metadata in a local SQLite database; video frame artifacts are not retained.

EVIDENCE HANDLING

Local retention

Source files and sampled frame files are temporary and deleted when the analysis service returns. SQLite stores report JSON and extracted metadata locally under the operating-system user profile. Deleting a record removes that report from the local history.
